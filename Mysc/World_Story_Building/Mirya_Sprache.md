# Mirya Sprache — Myriac Language Reference

_Working reference file. Edit freely. Parallel to the original Mirya Sprache.odt._

---

## Overview

**Myriac** is the ancient language of the land — spoken originally by dragons and the earliest humanoid peoples of the continent. It is no longer a living spoken language; its words survive in geographic names (mountains, rivers, forests, passes) and in the names of ancient settlements.

**Lurian** is the common tongue of Lura's people — derived from Myriac very long ago (comparable distance to Proto-Indo-European → German). The connection is faint: a linguist with both languages and the shift rules can trace roots, but you cannot guess the Myriac word just from hearing the Lurian one. Lurian sounds Japanese-influenced with open syllables and softer consonants. It is used for roads, newer settlements, and everyday speech.

## Myriac — Pronunciation Guide

| Letter / Cluster | Pronunciation |
|---|---|
| y (word-initial) | [j] — like German j |
| y (second letter of word) | [ü] — like German ü; overridden by word-final rule |
| y (after a vowel) | [ü] |
| y (after consonant, not second letter) | [i] |
| y (word-final) | [i] — overrides the second-letter rule (Dy, Ry, Cy → [i]) |
| x | [ks] — like x in Xylophone |
| c (word-final) | [k] — also when word origin had final c (e.g. Welca from Welc → [welka]) |
| c (word-initial, not before y) | [z] |
| c (word-initial, before y) | [s] |
| c (before e) | [z] |
| c (elsewhere) | [k] (hard) |
| ch | [ch] — like German ch in "Bach" / "ich" |
| ae | [a] 1st person / [e] 2nd person / [ä] 3rd person — shifts with grammatical person regardless of word type |
| oe | [o] 1st person / [ö] 2nd person / [e] 3rd person — same person-shift rule as ae |
| v (before vowel) | [w] |
| v (word-final) | [f] |
| v (before -on suffix) | [f] |
| v (before -a suffix, or elsewhere) | [fw] |
| Stress | generally on the first syllable |

### Word order

Standard Myriac sentence order is **SVO** — Subject, Verb, Object/Complement.

> *Ce drakon va drakael* — I fight the enemy  
> *Va solvama solvun ce* — The healer heals me  
> *Ce sae va Drakma* — I am a warrior  

**Modifier placement:**

| Element | Position | Example |
|---|---|---|
| Article (*Va*) | before noun | *Va brakev* — the fortress |
| Adjective | after noun | *Va brakev keva* — the large fortress |
| Multiple adjectives | stack after noun | *Va brakev keva xutona* — the large dark fortress |
| Possessor | before possessed | *Va drakma vorak* — the warrior's hand |
| Adverb / manner | before verb | *Ce breva drakon* — I swiftly fight |
| Size prefix | fused to noun | *Va kev-mitor* — the warhorse (not *Va mitor kev*) |

**Special positions:**

- **Time particles** (Kyv, Gat, Nuvol) precede the entire clause: *Kyv ce drakon va drakael* — I fought the enemy
- **Negation** (Nol-) fuses to or directly precedes the negated element: *Ce nol-drakon* — I do not fight
- **Sae / Oev** may front in identity and possession statements — *Sae ce Drakma* (formal/archaic register); *Ce sae Drakma* is equally valid and more conversational

### Negation

Myriac negates by prefixing **Nol-** [nol-] before any word. Nol is the number zero; as a prefix it means "zero of / the complete absence of." The prefix is written with a hyphen when clarity is needed, fused otherwise.

| Pattern | Example | Meaning |
|---|---|---|
| Nol- + noun | Nol-vaeur | no soul / soulless |
| Nol- + adjective | Nol-orvaka | untrue / not real |
| Nol- + verb | Nol-drakon | to refuse battle / to not fight |
| Nol- + pronoun | Nol-ce | nobody (from my side) |

> *Nol sae ce Drakma* — I am not a warrior  
> *Nol-myraev* — faithless / without faith  
> *Nol Korv* — not all / not every

**Nol-** marks *absence*. Where **Xul-** (shadow) creates oppositional or darkened semantic meanings — *Xulral* (sin = shadow on the sacred), *Xulvora* (false = shadow-speech) — Nol- simply removes the thing entirely. The distinction matters:

- *Nol-myraev* — faithless: has no faith (a neutral absence)
- *Xul-myraev* — apostate: actively set against faith (faith's shadow = opposition)

### Time particles

Myriac verbs carry **aspect** through their suffix (-un/-on/-an) but not tense. Time is marked by a single particle placed **before the verb**. The present is unmarked; only past and future require a particle.

| Particle | Pronunciation | Tense | Source |
|---|---|---|---|
| *(none)* | — | present | unmarked default |
| **Kyv** | [küf] | past | Kyv (ancient/of old) — the weight of what already was |
| **Gat** | [gat] | future | Gaton (light/dawn) — the light still coming |

> *Ce drakon* — I fight (now)  
> *Kyv ce drakon* — I fought  
> *Gat ce drakon* — I will fight  
> *Kyv gelun ce va ralev* — I arrived at the temple  
> *Gat solvun va solvama* — The healer will heal (ongoing)

Aspect and tense combine freely:

| Combination | Example | Meaning |
|---|---|---|
| past + ongoing (-un) | *Kyv selun ce* | I was traveling |
| past + completed (-on) | *Kyv selon ce* | I had departed |
| future + ongoing (-un) | *Gat solvun ce* | I will be healing |
| future + completed (-on) | *Gat solvon ce* | I will bless (once) |
| future + reversal (-an) | *Gat brevan ce* | I will return |

For immediate present emphasis (*right now*, at this moment), **Nuvol** [nu-wol] precedes the verb:

> *Nuvol voran ce* — I am speaking right now  
> *Nuvol ralun va raluma* — The priest is praying at this very moment

### Questions

Myriac marks any sentence as a question by appending **-ek** [ek] to the last word. The suffix is invariant — it does not change for tense, number, or word class.

> *De wocist-ek?* — Did you eat?  
> *Sae brakev orvaka-ek?* — Is the fortress true / real?  
> *Gat selon ce-ek?* — Will I have departed?

For **content questions** (who, what, where…) a question word built from the root **Bov** [bof] ("what / which / unknown") fills the slot of the unknown. The -ek suffix still appears on the sentence's last word.

| Bovtev | [bof-tef] | when? | Bov + Tev (time) |
| Bovorv | [bof-orf] | why? | Bov + Orv (cause) |
| Bovvel | [bof-wel] | how? | Bov + Vel (manner/toward) |
| Bovorn | [bof-orn] | how many? | Bov + Orn (many) |

**Content question examples:**

| Myriac | English |
|--------|---------|

## Myriac — Word Formation

Myriac compounds are formed by **smushing two words together** — syllables merge and drop rather than forming clean full-word compounds. The result should sound like one word, not two stuck together.

### General rules

- Drop the weakest syllable at the join point
- Final consonant clusters simplify
- Longer words typically lose their last syllable when they appear first in a compound
- Shorter words (3 letters or fewer) usually survive intact

### General derivational suffixes

| Suffix | Meaning | Examples |
|---|---|---|
| **-un** | movement / ongoing process | Galun (wind), Velun (rain), Kretun (death as descent) |
| **-ot** | sphere / orb | Gyrot (sun), Xugat (moon uses -gat variant with Gaton root) |
| **-ol** | time span / period | Gatol (day), Xutol (night) |
| **-or / -ur** | creature / living being | Galor (bird), Mitor (horse), Velur (fish) |
| **-v** | intensifier / directional | Trev (great), Naev (cliff), Xulv (black), Paruv (north), Gyrev (south) |
| **-a** | adjective / plural nominal | Bresa (stones), Treva (gigantic), Xarva (canyons) |
| **-ne** | archaic genitive "of the …" | Ralune only; no longer productive |
| **-lu** | open / bounded space | Galu (sky), Gelu (gate), Grelu (valley), Evlu (plain), Ralu (clearing) |
| **-ma** | person of / practitioner | Vaema (mage), Drakma (warrior), Solvama (healer), Raluma (priest), Mitoma (merchant), Kyvoma (elder), Yatuma (sage) |
| **-ak** | title suffix / one who holds | Trevak (noble/ruler), Merak (spouse/mate) |
| **-ael** | one bound in / relational suffix | Merael (ally), Drakael (enemy) |
| **-vel** | reach toward / directed action | Nuvel (to seek), Gatvel (hope) |
| **-rel** | emotional quality / felt state | Gyrel (joy), Myrel (love), Velrel (sorrow), Xulrel (hate), Drakrel (anger), Jakrel (courage), Trevrel (pride), Zolrel (shame), Nuvrel (longing), Yatrel (wonder) |
| **-an** | reversal / returning action | Brevan (to return); rare; marks movement back along the same path |

### Size prefix system

Four prefixes mark scale. They attach directly before any noun or adjective without altering the base word's form. The outer two (Nuv-, Trev-) already appear in place names throughout the continent.

| Prefix | Pronunciation | Scale | Notes |
|---|---|---|---|
| **Nuv-** | [nuf-] | microscopic / minute | From Nuv (small/deep); sub-everyday — particles, hidden things, faint traces |
| **Lev-** | [lef-] | small (everyday) | From Lev (small/slight); the ordinary diminutive |
| **Kev-** | [kef-] | large (everyday) | From Kev (big/large); the ordinary augmentative |
| **Trev-** | [trev-] | vast / great | From Trev (great/height); epic or geographic scale |

> **Lev-mitor** [lef-mi-tor] — pony · **Kev-mitor** [kef-mi-tor] — warhorse / destrier · **Trev-brakev** [trev-bra-kef] — great fortress · **Nuv-velun** [nuf-we-lun] — drizzle (minute rain) · **Lev-ralev** [lef-ra-lef] — roadside shrine · **Kev-yatuve** [kef-ja-tu-we] — great tome / deep knowledge

The standalone adjectives **Kev** and **Lev** describe intrinsic quality; the prefixes **Kev-** and **Lev-** modify another word. *Keva brakev* = a large fortress (it happens to be large); *Kev-brakev* = a great-fortress (a named category of structure).

### Verb usage

Myriac has no dedicated verb class. Any root can occupy the verbal position in a sentence. Three suffixes mark verbal meaning:

- **-un** — ongoing movement / process (*Selun* travel, *Gelun* arrive, *Solvun* heal, *Trevun* climb, *Mitun* follow, *Variun* fall, *Brevun* run, *Ralun* pray, *Vaeun* enchant)
- **-on** — single completed act (*Drakon* fight, *Gelon* enter, *Selon* depart, *Nuvon* wish, *Zolon* kill, *Velon* drink, *Kreton* curse, *Solvon* bless, *Orvon* vow, *Vaeon* cast)
- **-an** — reversal along the same path (*Brevan* return)

Some roots are inherently active and need no suffix: *Arev* (see), *Gorev* (make), *Voran* (speak), *Varun* (think), *Yatvel* (ask), *Vyrun* (remember). The grammar words *Sae* (to be) and *Oev* (to have) follow the same bare-root pattern.

## Lurian Common Tongue

Derived from Myriac very long ago. Used for roads, newer settlements, and everyday Luran speech. Ancient geographic features keep their Myriac names.

### Phonological shift rules (Myriac → Lurian)

Rules apply **in order**. Each rule feeds into the next — the output of one rule is the input to the following one.

---

#### Rule 1 — Person-shift flattening

The grammatical-person distinction encoded in Myriac vowels is lost entirely. Vowels collapse to their neutral base form before any other rule fires.

| Myriac | → Lurian |
|---|---|
| ae | → a |
| oe | → e |

---

#### Rule 2 — Consonant class shifts

Apply everywhere in the word (word-initial, medial, and final positions).

| Myriac | → Lurian | Notes |
|---|---|---|
| p | → h | bilabial weakening |
| v | → b | first step only; Rule 3 handles word-initial b |
| x | → sh | |
| z | → s | |
| my | → n | nasal-palatal collapse; surrounding vowels merge into the result |
| Cy / hy | → sh | any non-nasal consonant + y cluster; or h + y cluster |
| j | → y | |
| ch (word-initial) | → sh | |

---

#### Rule 3 — Word-initial consonant shifts

Apply after Rule 2, so v→b from Rule 2 is already in place before this fires.

| Myriac initial | → Lurian | Notes |
|---|---|---|
| b | → h | catches original b and v→b from Rule 2 |
| g | → k | |
| r | → n | |
| w before e / i / u / o | drops | wa- survives intact |

---

#### Rule 4 — Cluster breaking

Any two adjacent consonants that do not form a legal single onset receive an inserted **-u-** between them.

> elc (from Welc after w-drop) → el**u**c &nbsp;·&nbsp; Bres → B**u**res

---

#### Rule 5 — Vowel shifts (first pass)

| Context | Change | Notes |
|---|---|---|
| a immediately before l | → o | dark-l has a backing quality that raises a; does **not** apply before r |
| e in an open syllable | → i | open = the e has no following consonant closing its syllable |
| word-final -a | → -u | |
| word-final -on | → -o | |
| word-final -an | → -a | |

---

#### Rule 6 — Palatalization

| Sequence | → Lurian | Notes |
|---|---|---|
| si | → shi | feeds from Rule 5 (e→i can create si) |
| ti | → chi | |
| di | → ji | |
| hu | → fu | feeds from Rule 2 (p→h can create hu) |

---

#### Rule 7 — Liquid shift

**l → r** everywhere, without exception.

---

#### Rule 8 — Vowel shift (second pass)

**o immediately before r → u**

This cascades with Rule 7: any l that became r now triggers this shift if the preceding vowel is o. The chain a→o (Rule 5) → o→u (Rule 8) produces a full raising shift whenever a originally stood before l.

> Galu: a before l → Golu → l→r → Goru → o before r → Guru → then further shifts → **Kuru**

---

#### Rule 9 — Final consonant resolution

A word-final consonant that is stranded after cluster-breaking and vowel shifts resolves as follows:

| Final consonant class | Resolution | Notes |
|---|---|---|
| Unvoiced stops: k, t, p | drop entirely | most common outcome |
| Voiced stops: b, d, g | + repair vowel **-u** | |
| Sibilant: s | + repair vowel **-i** → then Rule 6 fires → **-shi** | |
| Liquid: r | + repair vowel **-u** | |
| Nasal: n | stays as-is | |
| Nasal: m | → n | |

---

#### Rule 10 — Final adjustments

| Change | Notes |
|---|---|
| Word-final **-e → -i** | softens all remaining final e |
| Intervocalic **b → w** | b between two vowels lenites to a glide |
| **Syncopation**: 4+ mora words drop the weakest medial vowel | usually the shortest, most central unstressed vowel |
| **Compound shortening**: long compounds shorten aggressively | one full syllable per component can vanish |

---

#### Worked example — Galu (sky)

| Step | Form | Rule |
|---|---|---|
| Start | Galu | — |
| g→k word-initial | Kalu | Rule 3 |
| a before l → o | Kolu | Rule 5 |
| l → r | Koru | Rule 7 |
| o before r → u | Kuru | Rule 8 |
| **Result** | **Kuru** [ku-ru] | ✓ |
